# 結果(CPU1コアで実施した `mini` 学習)

条件: 約3.4Mパラメータ、2,400ステップ、バッチ16×320トークン(約1,230万トークン)、約1時間。プロセスが2回落ち、チェックポイントから再開。
最終 val_loss(答え・証明部分のみ)= 0.2119。

## 算術・数学ベンチマーク(学習に出ていない問題、`eval_math.json`)
全体の完全一致 9.2%(218問)。分野別: 算術 5%、論理 20%、整数論 15%、代数 8%、離散 25%、解析 0%、力学系 2.5%。
=> 小さなモデル・少ない学習量では、計算問題はほぼ解けません。

## Lean証明ベンチマーク(`eval_lean.json`)
pass@1 = 85.4%、pass@4 = 87.5%(n=48)。ただし評価セットは「学習データと正規化後に同じ文を除外」して作るため、
ほぼ全てのファミリーが除外され、残ったのはペアノ(20問)と数値(26問)が中心です。結果は偏っており、一般化の強い証拠ではありません。

## フェーズ7(`phase7_mini/`)
- 対象の主張: **証明できませんでした**(モデルの試行20回、Lean厳格受理は0件)

  **ただし37件すべて、証明したのはモデルではなく既存の自動戦略(`baseline_tactics`)です。** モデルは先に解かれたため出番がありませんでした。
- 台帳のハッシュ連鎖は検証済み。
