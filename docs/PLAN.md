# BlindMathematics 研究計画(要約)

数学的知識をゼロから学習したAIを構築し、既知の研究史や未解決問題の情報に依存せず、
未知の整数写像の性質を独立に研究させる。最終実験では対象となる関数だけを提示する。

## 基本設計
- モデル: Decoder-only Transformer(ランダム初期化 / 事前学習 / 自己回帰)
- 環境: ローカルPC(GPUがあれば使用)
- 検証: Lean 4(Leanが受理した証明だけを形式的成功とする)
- 外部AI API: 使用しない

## フェーズ
1. 研究基盤の設計 2. 数学データセット構築 3. 基盤モデル構築 4. 数学的能力の育成
5. Lean 4統合 6. 未知問題の研究 7. 最終実験

## 研究上のルール
1. 対象問題に関する情報を学習データに含めない(`blindmath.data.audit` が検査)
2. 学習データの出典を記録する(JSONLの `source` / `license`)
3. 問題提示前に対象問題の情報を検索させない(外部API・ネットワーク不使用)
4. 仮説と証明を区別して保存する(`experiments/ledger.py`)
5. 計算結果と数学的証明を区別する(`kind` フィールド)
6. Leanが受理した証明だけを形式的成功とする(sorry・追加axiom・native_decideは不採用)
7. 既存の数学的知識を再発見した場合も記録する
